# Working on GrokBotDevTeam

Work within this repository. Use Python 3.10+ and the standard library. Set `--workspace` outside the release and project trees. SQLite stores state, history, and events. Discover native capabilities from the tools actually available on the platform.

Run `<venv>/bin/python -B -m unittest discover -s tests -v` and `<venv>/bin/python -B scripts/release.py check`. Use local fixtures in tests and report their results separately from live pilot results. Regenerate the manifest after changing release files. Publish only on explicit request.
