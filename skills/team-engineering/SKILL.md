# Implementation

Read the Git project rules and plan the change. Ask the Lead about conflicts. Implement the task and necessary regression tests. Stage new sources so they enter the snapshot. A commit is optional. Keep `runtime` outside the project.

Use [`project-verification`](../project-verification/SKILL.md). Update the docs with `technical-writing`. After successful verification run `task submit <id> --file submission.json` with summary, documentation, limitations, and run ID. Fix findings and resubmit a verified snapshot. Report budget or access blockers to the Lead.
