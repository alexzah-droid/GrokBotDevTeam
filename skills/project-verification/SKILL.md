# Project verification

Confirm the project and task. If there is no verification command, suggest a real argv to the Lead. Run `project verify --task <id>` as your own role. Check that the snapshot is unchanged. A nonzero exit, timeout, truncated output, or unavailable environment rules out `pass`. Report defects under your role's procedure. Coordinate base command changes with the Lead.

Gather independent evidence for criteria outside automated verification. State the run ID, snapshot, result, and unchecked areas. Claim visual or live behavior only when checked directly.
