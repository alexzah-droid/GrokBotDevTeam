# Documentation

- Architecture — boundaries, data flow, interfaces, and rationale.
- User — setup, example, result, limitations, and recovery.
- Agent — layout, owners, constraints, build and test commands.

Give a Git path or explain `not_needed` for each category. Check links and commands against the implementation. Run commands when possible. Summarize what changed, for whom, and how you checked it. Separate plans from working behavior.
